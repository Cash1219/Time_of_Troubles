## 重做方向

采用日漫游戏道具插画风格：清晰轮廓、明亮配色、简化阴影、透明背景；每张一个主要对象，至多一个辅助对象。缩小到 100 像素仍能辨认。无文字、徽章边框、大场景或写实金属堆砌。动物图保持动物本身形态，不用人形熊或复杂服装表达明星动物。
