# 英国海外资产补偿实装

已增加95级开局建筑：孟加拉种植园42级、英国工业41级、其他本土资产12级。采用补偿性新增，源地国家现有建筑未扣除。

孟加拉19级鸦片位于西孟加拉；东孟加拉增加染料11、烟草5、糖料1、香蕉4、丝绸2。全部新增种植园归英国本土诸郡庄园所有。

本土工业依已审核表分布。额外12级为约克郡铁矿2、米德兰兹铁矿2、本土诸郡家具1与贸易中心1、高地捕鲸1与伐木3、本土诸郡和西部乡郡港口各1。港口归英国政府；其余新增本土资产归本土诸郡金融区。

本土诸郡共获得12级建筑，其中9级属于41级工业补偿，其余3级为家具、贸易中心与港口。

已有建筑沿用当地开局PM，新建筑使用英国（或原版英属印度）现有同类PM。按纯原版基础价格与满员计算，41级工业的周直接利润40800、员工210100、人均年产值10.10；原草案45600使用了伦敦高档服装PM，实际兰开夏与约克郡普通服装PM较低，修正后比原剩余种植园42750低4.56%。未扣工资，不代表财政收入。

检查：总增量95级及分类正确；新增产权均属GBR；落点国家有效；PM标识有效；矿林捕鲸容量与农业容量检查通过；未减少其他建筑等级；修改历史文件语法解析通过。未进行游戏内新开局验证，旧存档不会自动得到这些开局历史变更。
