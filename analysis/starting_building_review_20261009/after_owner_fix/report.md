# 开局建筑全量对照（2026-10-09）

比较本机原版与当前模组的1836开局历史。所有同名历史文件以模组覆盖，新增文件追加。按州和建筑类型比较，跨国转移不算删除；等级来自add_ownership内各份额levels之和。未改建筑历史。

## 范围与口径

- 游戏没有给这些建筑逐小省份定位，不能判定某个省份具体有多少厂；逐省检查归属，逐州检查建筑。
- 原版建筑与模组新增建筑分开，新增体验建筑不能视为补回工具厂、农场等。
- 下表“削减”逐建筑类型累加；新增其他建筑不抵销该项。净减则比较原版建筑总等级。
- 包含两项DLC条件地标（国会山、中央公园），双方均各1级；未启用对应DLC时双方各扣2，差额不变。产权建筑、城镇中心、自给建筑、驻军等引擎动态生成项目不是本表的静态开局建筑。军队栏是历史中明确放置的军事建筑，并非全体军队单位数。
- 当前建筑地区归属失配0条，涉及0级，详见owner_mismatches.md。文件配置等级不等于游戏内已成功加载等级。
- 国家当前领土基准：单一归属州直接采用全州原版等级；分割州按当前省份数量比例估算，非历史实际分配，也非人口/GDP比例。地图变动州需结合地形重划审核。
- 未计算工资、生产方式效率、人口、法律、附属国上缴、市场规模及1848年的存档建设；建筑等级差不能直接换算财政收入。
