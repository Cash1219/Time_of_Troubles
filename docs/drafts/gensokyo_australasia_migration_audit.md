# 幻想乡澳大拉西亚迁移审计

审计日期：2026-09-25。

## 已完成的迁移准备

- 日本的 11 个州历史、人口和建筑数据已恢复为原版开局。
- 原日本版幻想乡的 38 名角色及相关历史文件已存入 `docs/backups/gensokyo_japan_pre_australasia_2026-09-25/`。
- `MRYA` 曾错误占有非洲的 Kazembe、Katanga 两州；两处现已恢复为原版 `KZM`。
- 幻想乡国家定义与本地化保留，但当前不再拥有日本领地，也不再生成角色。

## 地图容量

统计对象是原版 `map_data/state_regions` 的 `provinces` 色块；可用数已扣除原版 `impassable`。

|---|---:|---:|---|

新西兰北岛有 35 个可用色块，南岛有 42 个；可作为月都、天界、白玉楼等隔绝势力的第一期领地。

东巴布亚有 85 个可用色块，适合未来扩张为一片完整的异界大陆，但不必在第一期启用。

太平洋岛屿合计约 52 个可用色块，其中多数单独岛链不足 5 个色块；应按岛链合并为州，不宜逐岛建国。

## 第一版空间原则

- 博丽以悉尼—蓝山为东缘核心。
- 人里、魔法森林、妖怪之山、守矢、红魔馆、永远亭等地表势力压缩在澳洲东部连续地带。
- 中部荒漠保持不可通行，构成结界外缘。
- 西澳暂不纳入幻想乡分区，保留为未启用区域。
- 新西兰纳入第一版，用于需要物理隔绝感的异界势力。
- 月都、天界、白玉楼等以岛屿和事件通道表现跨界性质；魔界、彼岸可在大陆边缘使用投影，而不把所有异界都堆入西部。

## 实施要求

原版澳大利亚只有 7 个 State Region、新西兰只有 2 个。若按每个自定义州约 5–20 色块的目标分区，必须重写 `map_data/state_regions/13_australasia.txt`，并为新西兰同步重写相关定义；不能只改州历史。

第一版建议先完成澳洲东部与新西兰的州定义、国家领地、人口和建筑，再按国家数量决定是否接入东巴布亚和太平洋列岛。
