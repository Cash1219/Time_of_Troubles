# 受保护国与两寺位置调整（已应用）

上一版35块省份交换归属：命莲寺取得神灵庙原来在人里西部的13块内陆省份，神灵庙取得命莲寺原来的22块南澳沿海省份。对应首都州及州内人口归属同步交换；人口留在原地，命莲寺现在40万人，神灵庙50万人。两国连续且相邻。

21个博丽附庸的开局外交关系从 `vassal` 改为幻想乡专用 `tot_gensokyo_protectorate`，界面名称为“受保护国”。幻想乡结界盟约及博丽领导地位保留。沿用原版受保护国的高自治、不使用宗主地图色、允许自主发起外交博弈、不自动参加宗主战争等主要行为。

原版受保护国要求保护者为已认可国家，并有宗主等级要求。因此单独定义 `subject_type_gensokyo_protectorate`，允许现有博丽国家类型和等级，不要求宗主高于受保护国；没有给博丽增加威望或改变国家认可地位，也没有覆盖原版保护国规则。该外交关系只从幻想乡开局历史建立，不作为通用外交行动或拉拢报价向全世界开放。使用原版受保护国图标和界面名称。

静态检查通过：21个关系去重，全部目标国家存在，九个本次审计的国家连通，首都位于本国领地，人口文化宗教总量守恒。总人口19,610,000不变，人里耕地分配不变，其他版图、州耕地、建筑、矿产及海峡没有改动。尚未启动游戏验证。

## 对继续拆国的建议（未执行）

目前22国已经足够构成一个区域。继续拆国应以独立组织和独立玩法为依据，先把开局人物和产业路线补齐。两名有鲜明分工的核心人物也可以支撑国家，不要求每个利益集团都安排一个原作人物；普通行政岗位可以交给普通官僚。反过来，一个知名人物加上相同的建设流程，并不自动形成值得玩家重开一次的新国家。

命莲寺和神灵庙本身有足够组织基础和核心人物，适合保留。天狗有射命丸文、姬海棠果、犬走椛及饭纲丸龙；河童最明确的核心是河城荷取，山城高岭属于山童，不能无说明地算作河童班底。建议妖怪之山先保留统一政体，以河童工业、天狗政治/军事作为内部派系。扩地应连接现有山地、河谷和林区；之后若河童具备独立的工业机制与政治冲突，再考虑释放为势力。

月都面积大，但截图GDP约121K，低于妖怪之山约257K；面积本身没有说明其开局过强。先将南岛定义为低密度前哨，限制未来开发规模，比马上为一个人物加国更稳妥。如果最终缩到北岛，南岛应留给具有完整组织和不同玩法的势力，再确定归属；本次不先指定一个单人国家占位。

地灵殿南部沿海建议保留一个连续的地面出口与可规划港口的位置，让地下国家能连接外部贸易。其余大块沿海可讨论给旧都或神灵庙，但需一起核对库伯佩迪通行点、绿洲与现有海峡。不能只保留一个孤立港口点，也没有必要占据整条南岸。尚未据此改边界。

已有角色特质和立绘支持与各国开局角色初始化不是同一件事。仓库已存在魔理沙、爱丽丝、红魔馆主要角色、守矢三人、觉与恋、辉夜/永琳/铃仙/帝、幽幽子/妖梦、文/果/荷取等支持；本次检索未找到命莲寺、神灵庙、月都主要人物的对应具名特质，也没有在国家角色历史中找到这22个国别的成套初始化。下一步应做完整角色归属表，再安排开局职位，避免同一人物同时出现在多个国家。
