# 三国迁移与幻想乡特质方向（2026-09-30）

## 已实装的开局迁移

- 旧都由西澳的 30 省整体迁到南澳南岸的 26 省连续领土；其原西澳领土接入相邻的白玉楼。首都改为南澳。原有 50 万人口和建筑迁至南澳；原三级煤矿改成南澳已有资源位可容纳的三级硫矿，原铁矿等级保留。地灵殿在南澳的主体及海岸出口仍连续。
- 神灵庙由南澳迁到新南威尔士西部的 13 省连续内陆领土；原神灵庙领土接入相邻的太阳花田。原有 50 万人口和非港口建筑迁入新南威尔士，首都随之修改。原一级港口转给太阳花田，合并为其南澳两级港口。
- 命莲寺由原来靠西的 13 省迁到更东面的 13 省连续内陆领土，仍位于神灵庙以东。原命莲寺领土由神灵庙接收；新领土由人里划出。人口和建筑仍在新南威尔士州，首都不变。
- 此次地图共变更 104 个省份归属，没有调整州边界、地形、矿产上限、耕地或河流。各国原有的人口总数及文化／宗教人数保持不变；三州保留的文化本土均超过先前约定的 30% 门槛。旧都、白玉楼、太阳花田、两寺及人里剩余领土均保持陆地连通；地灵殿南澳主体连续，原有独立西出口保持原状。

## 地区特质：改为东方设定优先

先前草案给森林、矿脉、牧场等现实地理赋予了过多直接加成。这容易让特质像原版澳洲，而不像幻想乡。下轮应先按**势力的叙事功能与商品链**设计正面特质，再用地理检查可行性。负面特质只来自东方设定，不恢复沙漠、山地、疟疾等现实环境惩罚。

| 势力与地区 | 正面主题 | 产业效果方向 |
|---|---|---|
| 妖怪之山 | 河童水工、天狗网络 | 工具、机器、基础设施；避免泛用农业加成 |
| 魔法森林 | 魔法树海、魔法使工坊 | 木材、纸张、家具或小规模工具 |
| 人间之里 | 人间烟火、集市与耕作 | 粮食和食品加工，幅度克制 |
| 永远亭 | 迷途竹林、永琳药学 | 药物及相关原料；竹林视觉另行处理 |
| 太阳花田 | 幻想花海 | 染料／园艺和少量农业，不复制人里主粮优势 |
| 博丽 | 幻想乡结界、参拜路 | 行政、贸易通路与少量服务，不靠高产农矿追平 GDP |
| 红魔馆 | 红雾与馆内工坊 | 奢侈品或精工制品，兼顾塔斯马尼亚本部 |
| 旧都 | 鬼族锻造与地上贸易 | 铁、钢、工具；铜矿在原版实装前先用铁矿表示 |
| 地灵殿本部／地穴 | 地底热脉、核融合与地下回廊 | 特色发电及通道；保持地穴低人口，不施加现实荒漠惩罚 |
| 神灵庙、命莲寺 | 宗教与学艺中心 | 教士、教育、纸张或服务，避免复制普通工厂加成 |
| 冥界西岸 | 三途渡航、冥界庭园 | 港口、贸易、园艺与冥界特色商品 |
| 月都与外岛 | 月兔运输、月都工艺 | 港口、精密制造或特殊生产方法，按实际势力分布落地 |

实现时须区分州和国家地区：《维多利亚3》的 `state_traits` 影响整个州，同州多国会一起受益。例如新南威尔士现在有人里、神灵庙、命莲寺等，不应把其中一国专属的“寺庙学艺”直接写成全州特质。可共享的地理背景才适合州特质；势力专属的加成需另找只作用于其国家地区的机制。特质数值和负面效果暂不实装，等迁移版实际开局经济测试后再定。
