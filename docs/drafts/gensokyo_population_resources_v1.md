# 幻想乡人口与资源第一版草案

> 本文保留实施前的讨论与审计记录。人口与耕地已于2026-09-28实装第一版：总人口1,961万、地穴1万、可耕地1,100。当前有效配置与测试说明见 [人口与耕地实装记录](gensokyo_population_arable_applied_v1.md)，下文2000万人等历史草案不再代表当前配置；产业仍待讨论。

2026-09-28。范围为当前22个幻想乡势力实际拥有的澳大利亚、新西兰、斐济、瓦努阿图及少量周边岛屿，不包括尚未迁入的原版国家。只用于讨论与后续实施；没有改动游戏人口、资源和开局建筑，也没有进行实机平衡测试。

## 设计目标

先用合计2000万人作为计算基准，避免沿用原版殖民地的劳动力规模。这个数字是玩法选择，不是东方原作人口考证，也不是现实1836年人口。若改用1000万或4000万，应同步调整开局就业、农业容量和建设规模，不能只乘人口。

现阶段要解决的是各国能否正常就业、建设、交易和发展特色产业；长期上限需要再结合技术、自然人口增长和对外贸易测试。用户新增约束：前期高度限制或禁止外来移民输入，因此不把外部移民计入前期可用劳动力。科技tier2不等于开局已有相应工厂、资质和基础设施。

## 当前文件审计

按当前实际拥有土地的州统计，人口历史文件写有1,188,550人；其中326,334人的region_state归属与当前领土相符，另有55个人口创建块归属不符。19个开局建筑创建条目也指向不匹配的region_state。

这里的数字是静态代码记录，不能等同于实机加载人口；引擎和其他事件如何处理无效历史范围还须检查。13个势力在扫描到的历史范围内没有匹配归属的人口记录，应先处理原版NSW、SAS、TAS等旧范围。

当前相关州合计可耕地296。显式资源上限合计：煤148、铁183、铅120、硫84、木材64、渔业82、捕鲸30。发现型金矿、油田另算；地灵殿本部的非标准资源块不计入有效上限。

这些是地理州的总量，不是国家配额。同一州被多个势力分占，不能把全州资源完整赋给每一个国家。实际分州资源分摊需结合引擎与prime_land等定义核实；若需要精确控制某国的矿区，可以在不移动国家边界的前提下整理经济州。

## 前期限制外来移民后的岗位预算

原版不少基础工业生产方式每一级建筑约需要5000名员工；一个20级工厂据此约需10万员工，而不是整个工厂无论规模都只需5000人。实际岗位还会随建筑、生产方式和自动化改变，因此5000作为预算单位，不作为所有建筑固定常数。

按基础25%劳动人口比例估算：

| 全体人口 | 约可用劳动人口 | 全部用于5000人岗位时的理论级数 |
|---|---:|---:|
| 15万 | 3.75万 | 7.5级 |
| 30万 | 7.5万 | 15级 |
| 50万 | 12.5万 | 25级 |
| 100万 | 25万 | 50级 |
| 200万 | 50万 | 100级 |
| 360万 | 90万 | 180级 |
| 全域2000万 | 500万 | 1000级 |

最后一列只是就业量级换算；农业、矿业、军队、行政和服务业也占用劳动人口，不能把这些级数全建成工厂。工作资质、工资竞争和州之间分布还会进一步限制可实际雇佣的人数。

人口规划应从期望产业规模倒算。例如60级5000人规模的工厂约需30万员工。假设工业仅占全体劳动力的50%，且劳动人口比例为25%，则需约240万全体人口。这里的50%是设计场景，不是原版固定比例。更换为节省劳动力的生产方式后，需要重算原料和能源供给。

因此，小势力若保持普通原版岗位规模并允许一定产业扩张，可先评估30—50万人作为人口下限候选；主要工业国则按期望工业、矿业和服务业规模倒算，第一版120—220万人不自动保证充分发展空间。另一条路线是只给特色建筑更小的级数和岗位规模，同时同步缩放产出、投入、建设费用与其他等级效果，不单独把5000岗位改成500却保留原产出。

开局必须安排可用的非工业就业和必要供应链，预留可从自给农业转入工业的劳动力；不能靠等待外来移民填满空工厂。人口增长与政策提高劳动人口比例可作为后续空间，不计入开局已实现的能力。

外界输入、国内州间迁移、幻想乡国家间迁移是三个不同范围。用户已确定的是前期限制外来输入；幻想乡内部跨国流动是否允许尚未确定。实施时不能简单降低所有州移民吸引力，否则也会干扰核心州、绿洲与地下入口之间的人口配置。

本机原版law_migration_controls使用country_migration_restrictiveness_add=60，law_closed_borders使用101。它们是国家层面的限制，定义中没有只排除幻想乡外国家的来源白名单。严格区分外界与内部势力需要继续核实引擎筛选接口，或用额外的可控人口流动脚本；不能声称直接加闭关律就已完成这种区别。闭关律还附带阻止邀请鼓动者及外交杠杆相关效果，实施时要确认这些是否符合设计。

## 地穴低人口与自动化设施

2026-09-28最新方向：保留地穴普通建设权限，以稀少居民和特色建筑低人力需求形成经济侧重，不再实施常规建筑禁建或特色建筑白名单。这里是新设计草案，尚未写入游戏文件。

撤销原地穴40万人方案。地穴开局可先测试5000—20000人，以10000人作为首轮候选；这符合荒漠地表据点和分散地下设施稀少居民的方向。这个范围是玩法建议，尚未获确认为最终人口。原第一版地灵殿160万和全域2000万均须重新汇总，不为了保持旧总量把撤下的人口强塞进其他州。

| 州 | 人口草案 | 作用 |
|---|---:|---|
| 地灵殿本部 | 40万 | 首府、管理、加工与核心服务 |
| 爱丽丝泉绿洲 | 30万 | 地上物流、居住与小规模农牧 |
| 北方绿洲 | 15万 | 北方补给、矿业与通行节点 |
| 东部入口 | 25万 | 妖怪之山方向的交通和加工 |
| 西部出口 | 10万 | 彼岸方向的物流与补给 |
| 地穴地带 | 0.5—2万候选 | 少量维护人员和高度自动化能源设施 |

上述其余州仍保留第一版数字作为对照，未重新校准；按当前表地灵殿合计为120.5—122万人，全域基准相应为1960.5—1962万人。没有改变不可通行省份。地下居民仍需食物、有效市场连接和设施岗位。

首轮特色核聚变设施可先评估每级100—300名员工，配合工程师、机械师和少量维护人员，而普通基础工厂约5000人的规模继续保留。10000人口按25%估算约有2500劳动力：若每级200人，理论上最多约12.5级同类岗位，而且还需为其他就业和资质不足预留余量。实际开局机组数量须按生产方式所需员工和商品需求确定。

低人力只提高特色设施在小人口州填满岗位的可能性，不会自动让玩家或AI优先建设。特色建筑应在地穴设置更高的ai_value，并提供合理的盈利与供应链；不能承诺AI一定遵从偏好。机组建设费、设备维护、燃料或冷却系统投入以及可扩张上限共同限制产能，不能简单把5000人改成200人就给出大量廉价产出。

人口保持稀少需要同时处理地穴迁入：高工资、空缺岗位和大量可用工作可能吸引本国州间迁移，仅限制外来国家移民并不足够。原版有state_migration_quota_mult和state_migration_pull_add/mult，可作为这个州的限制候选，具体迁入效果仍须实测。没有查到本次可以直接设定“州人口绝对上限”的接口；低开局人口、低迁入与自然人口增长是不同机制。原则上不使用周期性删除居民来假造上限。

输电仍是独立待实现项。本机原版electricity具有local=yes，不能离开生产州。地穴只放核设施时尤其要解决消费去向，否则有核设施不等于本部已获得供电。可评估带容量、成本和损耗的输电机制，或可运输的魔法能源载体及地表转换设施；这两种目前都没有实现。

## 资源采用三层设计

1. 自然潜力：可耕地、矿山级数、林业、渔业与发现型资源，限制长期可扩张规模。
2. 开局产能：实际存在的建筑、生产方式、员工和所有权，决定初始供需。
3. 幻想乡特色：地下能源、制冰供水、结界维护等机制；尚未实现的不能当作已有产能。

木材、铁、工具、布料等建设投入必须有可交易的供应。不是每个小国都要有全套矿业，但需要真实可用的贸易路线、足够基础设施与能够运作的供应国。沿海国的港口、内陆国的陆路和地下连接需要分别检查，通行连接本身不是无限市场接入。

## 农业潜力与空间分配

在2000万人草案下，可耕地先以全域1000—1200级作为测试候选，比现有296提高约3.4—4.1倍。这个范围尚未以粮食供需模拟验证，也不是立即把各州统一放大。农业就业与初始乡村居民须同时匹配。

建议全域可耕地的区域分配中值如下，实施时应拆到真实农区，并检查各州可以种植的作物种类：

| 农业区域 | 全域占比候选 | 约1100级时的参考 |
|---|---:|---:|
| 人里与相邻寺庙、神灵庙农区 | 38% | 418 |
| 西南白玉楼及相邻适宜农区 | 20% | 220 |
| 新西兰、塔斯马尼亚及所用群岛 | 15% | 165 |
| 妖怪之山、守矢、魔界的适宜农牧地 | 15% | 165 |
| 南澳非荒漠农区 | 8% | 88 |
| 其他林缘、花田、绿洲与特殊湖岸 | 4% | 44 |

这些参考数字是区域总量，不能再次重复加到每国。把一块农区划给某国并不强迫它只能发展农业。

人里负责主粮和纺织原料；白玉楼承担西南农牧与食品的第二支柱。花田以已有植物园建筑所生产的观赏植物和果树为特色，避免把花田等同于大面积粮田。现有植物园属于城市娱乐建筑，不消耗可耕地，因此若希望园艺受土地容量约束，需要另做建筑规则，不能只给花田加耕地便认为特色农业完成。

魔法森林不必拥有大量粮田，但需要林业上限和可用工艺产业。妖怪之山拥有少量谷地农业，并不等于把整片山脉都设为高产农田。绿洲农业受供水约束；冰之领地的制冰提高用水条件属于魔法设定，应有设施投入或成本，盐湖本身不是可饮用淡水源。

## 矿业与能源方向

现实地理决定主要方向，游戏商品体系与世界观决定表达方式。澳大利亚地学局的资源图说明铁矿主要集中于西澳皮尔巴拉，黑煤主要在昆士兰和新南威尔士；不能只按国家性格给每国复制一套煤铁。

- 西北灵长园、后户及邻近地区：按具体地块承接西部铁矿与相关矿产潜力，保留运输难度。
- 妖怪之山与其西侧有效矿区：东部煤矿、部分金属矿与加工基础；具体矿区不要只按海岸线分。
- 地灵殿与旧都：地下金属矿、矿业服务和地热的候选地区；普通矿山与特殊地热建筑须分开定义。
- 红魔馆所在南澳：化工与制造可以发展，但铜、铀、盐不能不加说明就全部换算成铁或硫。
- 西南白玉楼：资源配置优先保留农业、林业和食品加工优势，不把西澳全国铁矿完整搬给西南。
- 新西兰与塔斯马尼亚：林业、农牧、渔业和分散矿产；不强行复制澳洲大型煤铁区。

煤、铁、硫、铅、木材等具体新增上限，下一步应按地块和商品链分别计算。石油保留发现型资源与时间进程，不因为现实21世纪有开发就全部成为1836年开局产量。铝土矿、铜、铀、天然气等原版缺少的商品，先记录对应矿区，后续决定新增商品或用明确说明的抽象表达，避免直接伪装成其他矿种。

当前自定义晶矿等仍写有buildable=no，魔力能源商品也有被注释的定义；这版不把它们计入有效供应。地热和太阳能尚无本次已实现的设施。地热可以作为局部工程特色；太阳能若采用成熟现代技术，需要另行说明科技或魔法生产机制。

## 开局经济的实施顺序

1. 修正人口和建筑历史的所属范围，并校验没有无主人口、重复人口和无主建筑。
2. 按总人口方案分配各国及各州居民，保留总量校验；文化、信仰和职业比例单独确定，不强行把全部居民换成单一新种族。
3. 配置匹配居民数量的乡村与城镇就业，补齐工具、木材、粮食、衣物和必要行政设施。
4. 把矿业潜力落实到正确地块，整理需要精确控制资源的经济州，保持已完成的国家版图。
5. 给地穴设置低人口和适度迁入限制，配置低人力特色设施的岗位、成本、AI偏好、基础设施与能源输送；普通建设权限保留。
6. 新开局检查各国有效人口、就业、资质、财政、市场接入和基础商品价格，再调整人口与建筑，不通过额外征服补足基础经济缺陷。

测试应分别观察开局、短期运行和科技升级后的供需。当前20万人、100万人等规模只说明大致建设空间，不能保证财政与贸易已经平衡。首轮不要同时叠加所有强力州特质、廉价魔法能源和高资源上限，否则很难定位问题。
