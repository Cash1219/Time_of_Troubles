# 南部版图与幻想乡附属体系调整（已应用）

按用户两张最新截图选择连续省份，调整60个省份的开局归属。没有新增省份、州、海峡或建筑；资源、生产方式及州耕地定义没有修改。

## 版图

- 红魔馆取得永远亭西南沿海3块省份，包括东侧海峡的大陆端点 `x11C030`。塔斯马尼亚与大陆据点通过两条现有海峡路线连接。
- 花田取得原神灵庙的全部22块南澳领地；原花田7块维多利亚省份归还人里。阿德莱德城市节点 `x4064E2` 因此归花田。
- 神灵庙迁到命莲寺本部正东侧，取得人里13块连续的新南威尔士省份；两国直接接壤。
- 圈中的魔法森林南部沿海4块省份给博丽，连同相邻的人里沿海4块省份一起调整，保证与博丽本部接通。
- 博丽最南端7块省份分别补偿人里3块、永远亭4块；悉尼城市节点仍归博丽。
- 迁移后的神灵庙首都州设为新南威尔士，花田首都州设为南澳。

## 幻想乡阵营与附属关系

## 阿德莱德和西海岸建议（未额外改动）

阿德莱德先留在花田，作为有人类居民的行政和贸易城市。花田本体可以在周边郊野，城市与花田不必是同一种景观；产业细节后续讨论。如果觉得一国兼有花田和都市规模过大，可考虑把城市设为内部自治地区，无须为一个地点再增加国家。

西岸优先加宽八云府：从与其直接接壤的内陆边缘省份划入小片连续土地，减轻目前细长海岸条带的形状。白玉楼保留西南农业本部，彼岸保留通往三途河及地下出口的方向。之后再局部整理三国接缝，避免用长走廊或孤立据点扩张。不建议单纯继续增加角色国家来填空。
