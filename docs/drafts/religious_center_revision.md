# 宗教中心：本轮实装设定

信仰价格40，普通商品（staple）；居民需求未调整。主线各档5000人，基础产出25／45／75，不采用此前60／120／200草案。按满员、每级、每周基础价核算，不计吞吐量、不扣工资。

## 普通仪式

固定州宗教皈依速度+10%，使用unscaled，不按建筑等级线性增加；不是文化同化，不解除法律及人口资格限制。特色仪式仍停用。城镇中心未改。
