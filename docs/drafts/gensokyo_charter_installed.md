# 幻想乡角色与结界共同体实装记录

2026-09-30。当前为修订 5，已写入运行文件。阵营名为“幻想乡”，核心身份为“幻想乡共同体”，原结界盟约原则更名为“乡内贸易”并更新描述。修订 4 已将众神眷恋改为宗教利益集团政治力量，并修复 GDP 排序动作语法。成员页现已增加人口排序及人口展示；需重启游戏验证。

修订 2：芙兰改为 `interest_group = ig_landowners`、`heir = yes`，不兼任集团领袖。蕾米莉亚仍是地主领袖，美铃仍是军方领袖；34 个国家—集团领袖组合没有重复。这里设置的是国家继承人的地主归属，不是增加一个引擎不存在的“集团继承人”职位。美铃与妖梦保留旧将领身份。

检查发现 10 人缺少通用“幻想乡”特质 `tot_group_sheet_019_trait`：灵梦、慧音、女苑、文、荷取、穣子、萃香、米斯蒂娅、纯狐、赫卡提亚。现已补齐，37 人均有且仅有一份。该既有特质带有原有修正，本轮没有修改其定义。纯狐、赫卡提亚仍只有占位个人设定，通用阵营特质不等于专属角色素材。

一些旧归属可能需要今后讨论：荷取属于工会、神奈子属于地主、永琳属于宗教势力、堇子属于乡村民众。本轮保留，不按人物职业重新分配。

帝的旧键 `ideology_sovereigntist` 无有效定义，修为当前版本的 `ideology_sovereignist_leader`，保留主权派取向。辉夜、堇子原来没有显式意识形态，本轮继续留空；其具体开局意识形态仍由游戏选择。旧天子、米斯蒂娅的统治者字段改用引擎有效的 `ruler = yes`。

## 阵营

八云府创建“幻想乡”，八云紫作为八云府统治者担任开局阵营领袖。24 国都是独立成员，删除原有 23 条受保护国关系。

- 自定义身份提供统一市场，避免市场依赖可替换的普通原则。
- “乡内贸易”原则增加加入接受度 300，并为全部成员提供 +10% 技术传播；加入资格限已有 24 国。
- 加入资格按固定国家标签名单判断，不检查文化、宗教、人口或角色特质。原版的加入外交条件仍然适用。
- “势力自治”原则允许按正常外交规则内部交战，不强制跟随成员战争，并为全部成员提供 +10% 基础设施。
- “众神眷恋”原则以 `member_modifier = { interest_group_ig_devout_pol_str_mult = 0.5 }` 给所有成员，包括八云府，提供 +50% 宗教利益集团政治力量。修订 4 替换了先前误用的教士人口政治力量修正；该字段有本机原版国家宗教法律和修正定义为依据。它增加集团政治力量，集团的最终势力占比仍按所有集团的政治力量计算，并非固定增加 50 个百分点。
- 修订 2 使用的 `participant_modifier` 虽列于随游戏附带的说明文档，但当前运行解析器在 `debug.log` 明确报 `Unexpected token`，旧教士加成没有加载。修订 3 改用原版实际代码和悬浮提示支持的 `member_modifier`；`non_leader_modifier` 才是排除主持国的字段。
- 只有结界盟约标为主原则，另外两项是本身份专用的普通原则。按原版历史方式先创建集团，再以 `add_principle` 逐项添加，避免原先三组都设为主原则的配置冲突。三项原则需在新开局中核实。
- 退出必须同时满足：加入至少五年、没有参战、凝聚力低于 20、集团对退出国的优势不高于 30。
- 基础凝聚力目标为 70，每一种共同市场短缺商品减少 2；开局当前凝聚力为 100。
- 首版暂不积累新原则授权，排除全部原版原则组对本身份的选择，防止重新套入附属化、禁战或强制参战规则。其他身份的原版原则内容保留。
- 八云府获得 500 外交影响力，抵消原版主持集团的固定成本；没有额外人口、声望或产业产出奖励。

引擎仍要求主持国。本轮只确定开局主持者，没有实现共同表决、领袖永久固定或禁止主持国踢人；这些不能仅靠原则完成。内部战争仍受其他正常外交规则制约。

## 成员页面的 GDP 和人口排序

修改的是国家集团面板 `gui/power_bloc_panel.gui` 的成员页。默认按当前 GDP 从高到低排列；GDP 按钮切换升降序，重新进入成员页或点击按钮时重建顺序。数值继续从国家对象显示。

GDP 和人口排名均包括主持国；固定的主持国介绍卡仍在上方。主持国和每个成员卡片显示实时总人口。原有名称、威望、优势排序以及搜索保留。列表使用当前查看集团的成员，查看别的集团也不会误取玩家自己的集团。没有猜测原版不公开支持的排序参数，而是用 `ordered_power_bloc_member` 分别按 `gdp` 和 `total_population` 生成顺序。

用户测试发现 GDP 排序列表为空。`debug.2.log` 中 23:37:46 的记录明确报告本页六处动作的 `Unexpected characters found at end of Statement`：连写 `[切换模式][生成列表]` 时，第二个操作没有被解析。修订 4 将每个操作写为独立的 `onclick` 或 `on_start`，按原版用法先生成列表再切换显示模式；名称、威望、优势按钮也采用独立动作。

检查器新增动作表达式检查，可拒绝旧版本的连写语法。引用与结构检查通过，修改后的版本尚未在游戏中点击验证。初次修改前 GUI 备份在 `docs/backups/power_bloc_member_gui_before_20260929_213005/`，此次修复前备份在 `docs/backups/power_bloc_member_gui_before_20260929_235612/`。

## 检查与边界

检查通过：角色唯一性、15 名恢复统治者、34 个唯一集团领袖组合、芙兰地主归属继承人、37 人均有幻想乡通用特质、意识形态/文化/特质引用、图标文件、三项开局原则及教士修正、24 国成员名单、零开局附属协议、原版原则覆盖内容与生成快照一致。

文化守卫也通过：允许已经记录的东岸三个省份转移、卡纳克交给天界、对应 56,004 人迁移、一个新港口，以及州地形惩罚清理和低于 30% 文化本土清理，详见 `gensokyo_map_cleanup.json`。耕地、资源、既有产业、宗教定义、利益集团定义和不可通行省份保留。初次实装与各修订的备份见 `gensokyo_charter_installed.json`，逐人政治归属也在该文件中。

需重启并新开局验证：八云紫和各角色是否正确生成、共同市场成员、三项原则分别占槽及显示数值、内部外交博弈、退出条件提示；进入成员页测试 GDP 升降序、搜索和其他排序。静态检查不证明这些游戏内行为已经测试。

## 八云府位置建议

推荐人里北缘、魔法森林南缘附近的交界地带，让主持国靠近东部主要势力。迁移时应整块迁移，不留西岸飞地；旧地按相邻边界分给彼岸与白玉楼等西岸势力。当前只提出位置建议，本轮没有改地块、首都或人口。

## 后续意识形态设计

已参考本机原版意识形态的法律组立场，以及原版现有法律。新名称和幻想乡政治主题可以自定义，机制仍通过现有法律的 `strongly_approve / approve / neutral / disapprove / strongly_disapprove` 表达。上一版概念稿没有完成完整法律立场矩阵，尚不能直接替换所有角色与集团。

下一轮应先列出每个新意识形态对治理、权力分配、公民权、宗教、经济、土地、劳动、教育与军制法律的立场，再校验角色和集团组合。当前不替换意识形态；只有芙兰的集团归属按用户指定修改。
