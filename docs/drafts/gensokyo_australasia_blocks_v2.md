# 幻想乡迁往澳大拉西亚：板块定位 v2

这份草案先确定势力群与地理关系，不据此直接划定省份边界。具体省份分配应在各板块的外边界确认后进行；澳大利亚与新西兰的原版殖民地、土著部落届时不保留为开局国家。

## 1. 东南生活圈

**位置：** 维多利亚、新南威尔士南部及其交界。

**势力：** 人间之里、太阳花田、命莲寺、永远亭。

人里是生活圈的主体。太阳花田位于其开阔边缘；命莲寺与人里相接；永远亭位于相邻但较偏僻的林地或丘陵。四者应构成一片可步行往来的连续地域。

## 2. 博丽结界与兽道

**位置：** 悉尼、蓝山及新南威尔士东部。

**势力：** 博丽、魔法森林、夜雀食堂。

博丽占据悉尼及东侧出口。魔法森林置于博丽西北方向的蓝山或山林地带，并与博丽接壤。夜雀食堂只保留少量省份，代表兽道上的交通和饮食节点，必须夹在人里与博丽之间，而非独立发展为大国。

## 3. 红雾盆地

**位置：** 艾尔湖及其东侧盆地。

**势力：** 雾之湖、红魔馆。

雾之湖占据艾尔湖及其东缘，作为朝向东南生活圈、博丽结界方向的前锋；红魔馆位于湖西或湖南，与雾之湖保持连续接壤。两者共同构成孤立但完整的湖盆势力群。

## 4. 妖怪之山、守矢与地灵殿

**位置：** 昆士兰东南至大分水岭。

**势力：** 妖怪之山、守矢、地灵殿。

妖怪之山占主要山脉与山林；守矢位于更高或更内侧、并与妖怪之山相接的山地。地灵殿不是独立地表板块：只在守矢近旁保留小型地表入口；其横向广布的地下洞穴体系通过设定、建筑、修正和事件表达，不以跨越荒漠的地表领土表示。

## 5. 边远异界

**位置：** 北领地、南澳偏远边缘，具体由地形和后续势力数目决定。

**势力：** 魔界、彼岸。

魔界和彼岸各自拥有单一地表投影区，避免穿越不可通行荒漠形成两段式领土。

## 6. 海岛诸界

**位置：** 塔斯马尼亚与新西兰。

**势力：** 月都、天界、白玉楼、八云府。

月都优先置于塔斯马尼亚。天界与白玉楼分布在新西兰南岛的高山和南部；八云府置于北岛或近海边缘。
