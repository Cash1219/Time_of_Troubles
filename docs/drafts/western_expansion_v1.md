# 西部扩张草案 v1

## 目标

将西澳与南澳地表从“西澳大利亚大国 + 地灵殿地表领”调整为数个有独立地域与玩法的势力。中央地穴地带继续不可通行，不作为普通国家之间切地的对象。

## 旧都（拟新 tag：KYTO）

- **位置**：阿德莱德港及其北侧矿业腹地。
- **规模**：约 25–35 个正常省份色块。
- **来源**：从地灵殿目前控制的南澳地表划出；不动库伯佩迪本部、入口或地穴地带。
- **角色群**：星熊勇仪为核心；伊吹萃香、茨木华扇可作为后续角色或事件线。
- **经济**：烈酒、煤炭/铁矿、金属加工、港口贸易。
- **关系**：与地灵殿互为地上贸易口与地下资源来源；不设为附庸。

## 彼岸（既有 tag：HIGN）

- **位置**：西澳东南部，靠近荒漠边缘但拥有一段可通行的绿洲—海岸走廊。
- **规模**：约 25–30 个正常省份色块。
- **来源**：从西澳大利亚划出。
- **角色群**：四季映姬、小野塚小町。
- **经济**：驿道服务、绿洲农牧、行政与宗教服务；后续可做三途川通行、移民与死亡事件。
- **关系**：避开阿德莱德，作为西部边境秩序的执行者。

## 后户之国（拟新 tag：UKDO）

- **位置**：西澳北部沿海至内陆边缘。
- **规模**：约 30–40 个正常省份色块。
- **来源**：从西澳大利亚划出。
- **角色群**：摩多罗隐岐奈；丁礼田舞、尔子田里乃可作为后续政治角色。
- **经济**：仪式、门户贸易、畜牧、珍稀矿产。
- **关系**：以门户网络影响东部势力，但版图保持连续，不做飞地。

## 灵长园（拟新 tag：RNGN）

- **位置**：南澳西北至中部绿洲外缘，毗邻地穴地带的地表入口带。
- **规模**：约 25–35 个正常省份色块。
- **来源**：优先从西澳大利亚与南澳地表的接壤带划出，不占不可通行荒漠。
- **角色群**：埴安神袿姬；动物灵相关角色后续作为事件或利益集团加入。
- **经济**：黏土、石材、陶瓷、人偶与工坊工业。
- **关系**：与旧都构成地表工业竞争，与地灵殿形成地下资源—地表加工链。

## 暂不独立建国的内容

- **畜生界**：先作为灵长园、彼岸和后户事件线的外部力量；等西部正常地表有余量后再决定是否拆为国家。
- **魔理沙与爱丽丝**：继续同属魔法森林，通过角色、利益集团和事件体现双核心。

## 建议落地顺序

1. 旧都（阿德莱德）
2. 彼岸（西澳东南）
3. 后户之国（西澳北部）
4. 灵长园（南澳西北—中部绿洲外缘）

每一步落地后都检查国家是否连续、州首府是否有效、是否压缩人里或地灵殿本部的必要空间。
