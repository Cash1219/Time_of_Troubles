# 幻想乡阵营章程与意识形态第一版方案

日期：2026-09-29。设计讨论稿，未启用运行时改动。

更新：该稿中的阵营“当前状态”为实装前记录。现已安装八云府主持的独立成员共同体，见 [实装记录](gensokyo_charter_installed.md)；本稿的新意识形态仍未启用。

用户已确定：保留原版八大利益集团，特殊需要以后扩展；幻想乡的集团与角色意识形态不使用原版条目，可适当复用本模组已有条目。

## 阵营的目标与当前状态

目标：独立成员、共同市场、可内部交战、自愿合作、严格退出。博丽没有宗主权；引擎仍需技术上的集团主持国，政治共同决策要另写程序。

当前运行代码仍然是 `c:HAKR` 创建 `identity_sovereign_empire`，配 `principle_vassalization_1` 与 `principle_market_unification_2`，并在外交历史中创建 23 个受保护国。前几份研究稿未加载，因此这些设置尚未替换。

## 身份、原则和程序的分工

| 层次 | 应承担的设置 | 不能单独实现的事项 |
|---|---|---|
| 集团身份 | 共同体基础身份、共同市场底座、入退资格、凝聚力计算、授权进度 | 没有查到无领袖、共同领袖或禁止踢人的直接身份接口 |
| 集团原则 | 加入接受度、经济/研究/运输修正、合作等级；也可以提供供脚本读取的政策标记 | 不能把事件效果或 `can_leave` 随意写进原则；没有查到原则中的退出判定/投票钩子 |
| 规则、事件、日志、脚本界面 | 退出申请、持续时间、表决、外敌动员、自愿回应、战后处理 | 用一个标记不会自动创造上述程序，必须实际消费这个标记 |
| 开局历史 | 主持者、24 国成员名单、初始原则、删除受保护关系 | 不会自动更新已有存档；仍需新开局验证 |

推荐把共同市场的 `power_bloc_customs_union_bool = yes` 放在身份上，避免主持者替换一个原则就使市场分裂。原则仍是可见政策主体，但共同体底线不依赖可替换的经济原则。

### 第一版原则设计

| 原则组 | 第一版内容 | 后续扩展 |
|---|---|---|
| 结界盟约 | 提高集团加入接受度；退出必须走许可程序 | 不同等级由退出规则读取，调整年限、申请等待和审批条件 |
| 势力自治 | 排除禁战与强制参战原则；自愿结盟和选择参战方 | 有限战争、是否允许灭国与吞并需要单独设计外交博弈/战后程序 |
| 互助协作 | 先用贸易、运输、建设或研究中的少量明确修正 | 多等级增加合作效率；不自动设置文化/宗教统一 |
| 外界往来 | 先明确是否允许对外贸易/投资，不直接开放外来人口输入 | 对外政策与外敌响应通过法律、事件及 AI 逻辑执行 |

这是四组候选，不要求全部开局占槽。第一版可只加载结界盟约和互助协作，自治作为固定基础规则；外界政策待产业与移民方案确定后追加。现有模组额外原则槽根据集团等级/成员数解锁，不应假定幻想乡开局全部拥有。

“势力自治”没有一个现成 `allow_internal_war = yes` 效果。原版仅在集团持有 `power_bloc_disallow_war_bool = yes` 等条件时因集团身份禁战。因此必须排除相冲突原则，而不是加一条空自治原则就宣称实现。

至少排除 `principle_group_defensive_cooperation`：三个等级都禁内战；排除强制参战的 `principle_aggressive_coordination_3`；排除附属化原则和提供领袖强制政体/宗教权的内容。可以在相关原版原则组追加 `blocking_identity = identity_tot_gensokyo_charter`，或用原则的 `incompatible_with` 指定冲突。覆盖原版组时保留它们的现有其他设置。

`possible`/`visible` 主要控制选择资格/展示，不能据此宣称禁止移除、踢人或 AI 行为；原则兼容规则也不能取代完整的主持权限限制。

### 经本机核实的代码骨架

原则文件中的评分片段：

```paradox
principle_tot_gensokyo_boundary_1 = {
    icon = "gfx/interface/icons/principles_icons/market_unification.dds"
    background = "gfx/interface/icons/principles_icons/principle_tier_1.dds"
    power_bloc_modifier = {
        power_bloc_invite_acceptance_add = 300
    }
}
```

自定义身份内的基础判定片段：

```paradox
power_bloc_modifier = {
    power_bloc_customs_union_bool = yes
}
can_leave = {
    tenure_in_current_power_bloc_years >= 5
    has_variable = tot_gensokyo_exit_authorized
}
```

事件检查原则时使用集团作用域：

```paradox
power_bloc = {
    has_principle = principle:principle_tot_gensokyo_boundary_1
}
```

原版 AI 退出使用 `invite_to_power_bloc` 接受评分，退出阈值为 -100。300 是待测设计值，不是百分比或永不退出保证，而且也提高外部入盟接受度。严格退出资格由身份执行；原则等级通过事件或 scripted trigger 读取后改变审批条件。

上述片段没有完整身份定义、原则组、定位文本或审批事件，不是独立可加载文件。

## 八大利益集团的自定义基础意识形态

保留集团键、名称与基本经济组织，不按角色另拆集团。以下八项均拟新增为幻想乡限定的集团意识形态，非原版意识形态换显示名。

| 集团 | 新基础意识形态 | 第一版法律方向 |
|---|---|---|
| 地主 | 门第秩序 | 家族财产、世袭与等级治理；不自动加入原版奴隶制/父权立场 |
| 宗教势力 | 信仰维护 | 信仰活动、宗教教育与信仰服务；不同宗教路线由人物与国别配置区分 |
| 知识分子 | 求知文教 | 教育、识字、研究与行政能力；不统一预设反宗教或共和主义 |
| 实业家 | 技术经营 | 工业、专业技术与经营；经济制度争议由领导人的具体立场体现 |
| 军方 | 专业守备 | 专业军事、警备、执行能力；不默认支持对外扩张或全面强制参战 |
| 小市民 | 地方行会 | 商店、手工经营、地方治安与财产；不自动套用民族优越立场 |
| 乡村民众 | 乡土经营 | 土地使用、农牧业、地方生活与迁移节制 |
| 工会 | 民生劳作 | 劳动保护、教育、医疗与劳动组织；不默认绑定某种政体 |

集团基础只覆盖有必要表达的法律组，未写的法律不强行表态。角色领导人意识形态与集团基础立场的互动仍遵循游戏机制，因此必须测试国别政治结果，而不是只看显示名。

集团特质与意识形态分开：本轮“不用原版意识形态”不等于已经要求全部原版特质也禁用。宗教本体更换仍是单独工作，不能把新意识形态当成宗教替换已完成。

## 角色意识形态及 37 人分配

以下均为玩法设计，不是原作给出的政治意识形态。名称可继续调整。一个角色只有一个主意识形态；附加个性、私人关系与外交目标使用角色特质/变量/事件。一个集团同一时间只安排一个集团领袖，其余角色可担任统治者、军官、执行角色或事件角色。

| 主意识形态 | 建议角色 | 法律方向与复用方式 |
|---|---|---|
| 结界均衡（新） | 博丽灵梦、八云紫 | 管理外界人口流入、维持基本秩序、允许信仰与势力差异；政治上不把共同体等同于博丽领袖制 |
| 自主领治（新） | 蕾米莉亚、辉夜、幽幽子、天子、古明地觉 | 自主领地治理、任命行政、既有财产与领导权；不附带性别权利限制 |
| 乡土信仰（新） | 诹访子、早苗 | 信仰维持与地方服务；不自动强迫其他国家改宗 |
| 开发协同（新，参考旧“实力至上”） | 神奈子、荷取 | 干预主义、专业技术与任命行政、反对禁工业；保留神奈子在宗教集团、荷取在实业家中的差别 |
| 求知研究（新，参考旧“古典文学部主义”） | 帕秋莉、永琳、爱丽丝 | 教育、专业行政与研究；删除学校社团制度的偏好，其他社会议题不凭空推断 |
| 自由创作（幻想乡版本，参考旧同名条目） | 魔理沙、射命丸文、姬海棠果、堇子 | 研究/表达与个人活动空间；与本版全体前期限制移民相区分，不因此自动支持开放外界边境 |
| 聚落守护（新） | 慧音、妹红、美铃 | 公共教育、基础医疗、地方治安与防卫；按知识分子/军方等组织身份分配，不把角色全部塞一个集团 |

| 共存自治（新） | 萃香、因幡帝、小町、赫卡提亚 | 地方自主、信仰与人群共存、限制过度管制；不同集团可以共享这一主立场 |
| 地方振兴（直接复用模组旧条目） | 秋穣子、幽香 | `ideology_local_revival_leader`；小农土地、农业、地方保护与迁移控制 |

| 游离政治（新） | 古明地恋、芙兰 | 不强行赋予法律偏好；第一版优先作为事件角色，不让其自动成为集团领袖 |

## 复用旧意识形态的核查

已检查 `tot_character_leader_ideologies.txt` 中“事务所经营”“地方振兴”“自由创作”“实力至上”“古典文学部主义”：这些键不属于本机原版意识形态，引用的法律键均能在当前原版或模组定义中找到。

仅“事务所经营”“地方振兴”建议直接复用，其余创建幻想乡版本。旧“古典文学部主义”含社团法律，旧“自由创作”含开放移民偏好，需按本方案筛选。旧“门风秩序”含限制女性工作/参政的立场，不因名称像家族治理而直接移给红魔馆。

直接复用会共享同一条目，后续若想改幻想乡而不改变其他作品角色，应复制成幻想乡专用键。该表允许继续使用原版法律键；用户排除的是原版意识形态定义。

## 意识形态实装与验收

1. 新增 `common/ideologies/tot_gensokyo_ig_ideologies.txt` 与 `tot_gensokyo_character_ideologies.txt`，角色条目标记 `character_ideology = yes`。
2. 在现有八个 `zzzz_tot_*` 集团覆盖中，幻想乡限定初始化移除原版集团基础意识形态、加入新基础。保留其他国家的原有设置。
3. 调整幻想乡集团的自动角色意识形态候选与权重。不能只改命名角色，任由新生成集团领袖继续使用原版条目；也不能全局禁止原版意识形态而影响其他国家。
4. 恢复资产角色的开局创建，显式指定角色意识形态、集团和职务，避免同国同集团多人同时宣称集团领袖。
5. 审查技术/法律/事件中 `add_ideology`、`remove_ideology`、角色替换等路径，避免游戏推进后再次注入原版条目；按实际路径做幻想乡例外，不靠每月强行清空所有角色。
6. 新增定位文本；核对法律立场组、政治影响、角色生成、集团政治力量和政体兼容。
7. 新开局检查全部 24 国的集团基础、命名角色与自动生成角色；推进后复查未回落到原版。阵营同时测市场、退阵、内战、踢人、原则升级和主持资格。

本稿只确定可供审阅的方案；尚未实装意识形态或替换现有阵营。
