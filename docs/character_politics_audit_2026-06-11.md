# Character Politics Audit (2026-06-11)

审查范围：
- 仅审查 `common/history/characters` 下独立角色文件。
- 不重复审查 `TOT_characters.data`、`VMT_characters.data`、`demo_characters.null`、`reserve.null` 这类汇总/镜像文件。

判定口径：
- 以当前版本自由度更高为前提，不再为旧版“强行配额”自动辩护。
- 允许作品主题、二创世界观、国家叙事对 IG/意识形态有明显影响。
- 重点抓三类问题：模板痕迹过重、角色气质明显冲突、主角/统治者定位失焦。

评级说明：
- `A`：整体合理，可基本保留。
- `B`：大体能用，但有明显模板味或若干角色值得微调。
- `C`：建议重点重做，角色政治定位和当前版本目标不够匹配。

## 逐文件结论

## 最后结论

- 当前模组里最常见的问题不是“完全乱写”，而是“旧版本配额思路还留着”。
- 最值得修的不是那些已经很风格化的国家，而是 `IG 分得开、意识形态却没人物味` 的国家。
- 修正效率最高的方式通常不是推倒重做全部，而是：
  - 先保留大致合理的 IG；
  - 再把全员 `moderate`、全员 `pacifist`、或明显填空式意识形态拆开；
  - 最后才处理统治者/主角是否需要更换。
