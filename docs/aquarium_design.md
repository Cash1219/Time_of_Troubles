# 水族馆：当前实装

采用水生动物展览3000人、动物互动2000人、水循环设备减人。删除独立场地和科普组，将玻璃设施、讲解及基础教育并入展览线。保持展览价40、动物表演60，不改居民需求。每个主PM最多5种投入，每个PM至多1个科技。

水生动物统一由展览线通过观赏动物商品供应，互动线使用同一批动物，不再重复购入观赏动物。鱼代表饲料而非展品，互动线鱼为活动额外饲料。服务为训练、讲解、接待及节目组织，电力用于互动设施和节目。玻璃代表水箱、观察窗及展示设施维护。高级档包含此前展区和节目。

## 开局及用工

AQO在达尔马提亚开局有5级水族馆，基础档观赏动物总需求25，现通过配置CSV补同地区1级规范繁育、人工饲养的动物培育园，产量25，同时补药学。水族馆开局指定淡水生物、饲养员投喂、人工养护。建筑保持浪漫主义I解锁；培育园配方与居民需求未改。尚未启动游戏验证。

主线各档职业构成（劳工／店主／技工／职员）：展览为2500／300／0／200、2400／300／200／100、2200／200／400／200、2000／200／500／300；互动为1700／200／0／100、1600／200／0／200、1400／100／300／200、1200／100／400／300。原场地及科普定义保留供旧引用使用，建筑已不再启用。
