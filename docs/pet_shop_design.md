# 宠物店：当前实装

建筑由药学（II）解锁，开局为 0 级。每级代表店铺及配套业务的产业集群；单组主线每档固定 5,000 人。高档包含此前经营内容，时代表示供货和照护条件的发展，不表示猫犬历史上比鸟鱼更晚成为宠物。

体验（价格40）抽象购宠、养宠指导、陪伴及照护业务带来的整体体验。观赏动物（60）为动物培育园供应；本店额外的合成食品（30）用于到店后的照料，工具（40）代表笼舍及照护器具。主线不消耗服务，不改居民需求。
