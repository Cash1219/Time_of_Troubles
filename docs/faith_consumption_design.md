# 信仰商品本地化与消费设定草案

日期：2026-10-09。

## 1. 已实装

`common/goods/tot_goods.txt` 中 faith 设置为 `local = yes`，删除 `traded_quantity`、`convoy_cost_multiplier`。基础价40、staple分类、痴迷机会与威望参数保留。宗教中心PM的投入、产出、人手和科技未改。

信仰代表本州宗教场所提供的讲经、仪式、祭典及社区活动，不代表信仰身份本身可以买卖。当地消费只能依靠当地供给，不能通过跨州市场或国际贸易集中供货。定义已核对，尚未进游戏检查。

## 2. 当前需求，尚未变更

- 仍在 `popneed_services`，原版消费包从生活水平10开始。
- 默认商品为services，experience保留现有替代项。
- faith权重0.8、供给份额对权重的作用上限0.4、最低供给份额系数0。
- 不设单独的全民固定宗教消费预算。没有faith供应或不参加宗教活动时，普通服务仍是替代项。
- 不给宗教中心保证销量。上述0.4不是最终消费份额的40%硬上限。

## 3. 拟定动态消费倾向

**以下尚未实装。前提是引擎实测确认pop_needs的weight支持动态脚本值，并能提供人口/州/国家作用域。** 若前提不成立，教士判断接口存在也无法自动改变居民需求。

信仰目标替代权重：

`W = 0.8 × 政教法律系数 L × 本州教士覆盖系数 C`

其他两个参数先维持0.4和0。不改变服务组预算，也不修改experience条目。W是替代偏好，不是信仰实际购买量或总需求的乘数。

### 政教法律系数

| 法律 | L | 教士系数为1时的信仰权重 |
|---|---:|---:|
| 国教 | 2.00 | 1.60 |
| 信仰自由 | 1.25 | 1.00 |
| 完全分离 | 1.00 | 0.80 |
| 国家无神论 | 0.10 | 0.08 |

米利特制度与有经者等国教变体拟归入国教系数。采用法律类别而不是国教具体宗教区分，避免幻想宗教获得无依据的优劣待遇。完全分离只表达宗教不由国家主导，不等于居民普遍无神论。

### 教士覆盖系数

使用本州属于clergymen人口组的人口占比r；这是职业人口口径，不能自动等同于在岗教士人数占劳动力的比例。已有 `pop_type_percent_state` 判定接口可以分档判断；具体语法与运行时作用域仍须实测。

第一版参考分档（**未按开局实测分布标定**）：

| 本州教士职业人口占比 | C |
|---|---:|
| 小于0.5% | 0.80 |
| 0.5%至不足1% | 0.90 |
| 1%至不足1.5% | 1.00 |
| 1.5%至不足2% | 1.10 |
| 2%及以上 | 1.20 |

法律是主要差异，教士最多使该基础权重降低或提高20%。不按每名教士创造固定订单，不要求教士为0时宗教消费也为0。正式实装前，须用开局州的人口与职业分布重新确定阈值；以上仅为完整草案的示例。

国教信仰权重范围1.28—1.92；信仰自由0.80—1.20；完全分离0.64—0.96；国家无神论0.064—0.096。商品价格与供给依然影响市场结果，不能称其为实际消费量的90%降幅。

### 无神论人口差异

另一个可测试的独立方案：在atheist宗教定义中添加faith商品禁忌。按原版禁忌机制降低这些人口的宗教商品需求倾向；现有全局 `TABOO_DEMAND_MULT = 0.5` 保持，不为单个商品改变全部宗教禁忌。

禁忌按人口宗教生效，法律系数按所在国家生效。完全分离国家的无神论人口也适用禁忌；国家无神论下尚未皈依的人口仍与无神论人口有差异。禁忌机制不是上述W公式中的同名权重字段，实际叠加效果需单独观察。

## 4. 消费包预算与贫困人口

第一轮保留原版服务组消费包，不另增总支出。代表档预算如下：

| 生活水平 | 服务组预算 | 信仰消费入口 |
|---|---:|---|
| 1—9 | 0 | 暂无居民入口 |
| 10 | 23 | 与服务、体验共同分配 |
| 15 | 61 | 同上 |
| 20 | 114 | 同上 |
| 25 | 207 | 同上 |
| 30 | 397 | 同上 |

这些数字是消费包预算配置，不是faith件数或货币支出的独立固定份额。法律和教士改变组内选择，不给某一商品单独追加预算。

暂不把宗教消费推到1—9档。若以后希望贫困人口也有此消费，需要另外审核提前服务组或新增兼容替代需求的预算，不能仅凭faith的staple分类实现，也不在本次本地化中顺手更改。

## 5. 本地供给与验证

- 原版城镇中心教堂仍产services，本次没有转为faith。当地缺faith时保留服务替代；宗教中心作为更大规模、可主动建设的供给。
- 不为了本地化给每个州自动放置宗教中心。现有开局宗教中心保持原配置，先检查本地买卖单与盈利。
- 教士包含原版其他建筑的职业人口；宗教中心也增加教士。因其与供给存在反馈，采用较小调整范围和硬上限，避免持续建中心就无限抬高消费。
- 本州本地商品仍会使用引擎处理本地与非本地替代商品的供给比较；不能把市场卖单直接误读成本州销量，也不能从权重推算固定消费比例。
- 测试至少覆盖四种法律、无神论与其他宗教人口、不同教士占比、有/无本地faith供应，以及换法律后的更新。动态接口未确认前，不将候选脚本接入正常模组。

### 法律面板提示

`country_tot_faith_consumption_hint_mult` 是自定义展示修正，不接入引擎消费功能，也不由需求脚本读取，AI评分为0。法律值为国教、米利特制度、有经者+100%，信仰自由+25%，完全分离0%，国家无神论−90%。这些百分比对应法律系数L减1，不表示商品最终消费量的固定增减。完全分离的0值可能不在默认修正列表显示，需游戏中确认；不为强制显示伪造非零效果。

中文名称为“信仰商品消费”。由于动态权重尚未验证，描述明确提示这是预定效果、尚待验证。正式接入法律动态脚本后，再更新描述。未来若调整L，必须同步更新各法律的展示数值，避免面板与脚本不一致。
