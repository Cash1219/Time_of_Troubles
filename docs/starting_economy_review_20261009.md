## 恢复与补偿建议顺序

1. 先修建筑及人口地区归属，保留商品和经济设计。萨哈林分割州需要指定落点，不能将EZO全部机械替换成任意新国家。
2. 核实军队历史是否叠加，确定采用哪一套开局编制，避免把补偿全部消耗在额外军费上。
3. 审核四个净减州的港口恢复，再审各项被替换的农渔建筑是否真需要补回。
4. 按当前领土、人口、市场连接、生产建筑、行政与军费负担研究国别补偿。分割州的省份数量比例基准仅用于筛选，不能直接作为分配厂房或现金的标准。
5. 英法如果仍偏弱，应研究稳定的产业／税基与开支匹配，以及失去附属国收入造成的缺口；不能仅据静态建筑等级给统一百分比财政补贴。
