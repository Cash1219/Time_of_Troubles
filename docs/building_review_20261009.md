# 普通建筑第一轮修改后的总复核

## 范围与结论

2026-10-09，核对15种启用的模组普通经营建筑，以及增加奶业组的原版畜牧场，共16种、8330种理论组合。社团、乐队总部暂放；金色大厅合同与纪念建筑、停用建筑不纳入。

本轮只写复核工具与报告，不调整PM、价格、居民需求或科技。详细数值见 `analysis/round_review.md`；全部组合见 `analysis/round_review_combinations.csv`。运行 `python tools/audit_round_review.py` 可按当前代码重新生成报告。

整体无需再次全面重做。未发现当前可选PM引用未知科技、一个PM要求多个科技、负职业人数、零员工生产、单PM投入超过五种、模组主产升档员工总量变化、缺少中文名称或开局PM与当前组不匹配的问题。开局配置检查通过：全配置60条启用记录、128级；本复核范围内45条。国家起始科技脚本静态展开未发现开局门槛缺项，但不替代实际开局测试。

- 娱乐出版社“自营发行”：`pm_ent_press_distribution_local.dds`。

- 娱乐出版社“专业发行”：`pm_ent_press_distribution_export.dds`。

建议补对应图标或暂用现存纹理；本轮未替换。

继续检查PMG图标后，另发现20处缺失引用：游乐场2、娱乐出版社2、谷子工坊5、咖啡厅6、乐器工坊1、综合出版社2、舞台2。舞台两处为舞台设施和观演服务引用的 `gfx/interface/icons/generic_icons/sales_icon.dds`，该路径不存在。总共24处引用（部分重复指向同一缺失文件）；完整路径见机械报告。文件缺失不直接证明具体GUI如何显示，但应修复引用或补齐资源。

## 最值得进一步核对的经济项

1. **游戏工坊成熟档偏强**：全高档毛利30.97%、3000人、年产值60.67。IV时代可用最高营业组合已58.93，说明较强收益在最后一档之前就形成。相比谷子45.24、舞台49.40略高，应优先复查机械和电子线的产出、运营省工幅度；用户曾要求高科技及复杂产业链获得稍高收益，故不直接判定必须削弱。
2. **咖啡厅选择性菜单略强**：全高档52.38，但全组合最高56.53，是拿铁、海鲜焗饭、主题公演、冷藏设备，关闭茶和甜品，4300人。完整主线不是人均效率最优解。这是菜单选择价值，不能强迫全开；可作为轻微复调候选。
3. **水族馆高级自动化压低毛利**：全高档27.08%，3000人、年产值45.07；商品差额2600，参考周工资83.65，扣工资后仍2516.35。低于30%并不等于亏损，人口利用效率与原先已认可的设备取舍相符，不建议仅为达30%而增产。
4. **牛奶数量例外已确认**：传统挤奶投入谷物2产奶4，机械化挤奶谷物3产奶8，鲜奶谷物7产奶15，冷藏鲜奶谷物9产奶20。用户2026-10-09认可为限制早期供给使用非5倍数整数，保留现值，不再列为待修改问题。

## 不应误判为问题

- 私家庭园默认毛利80%，最高毛利84.62%，但默认年产值10.40、全高档40.95；农业投入较低，与原版农业结构相近。仅因毛利高而增加材料没有必要。
- 宗教中心年产值4.16—14.04，带皈依功能，已按原版服务及艺术建筑而非工业收益定位。
- 宠物店、动物培育园、乐器工坊和综合出版社全高档年产值50.1—50.7，只是参照值附近，不建议为50的数字边界强行削弱。
- 游戏工坊5种负商品差额组合均涉及关闭主产或主产不足；舞台6种为最低主线配最高省工。保留玩家自主选择，不强制开满或锁死设备。
- 动物园、水族馆、宠物店、培育园的低主产配高级设备会低毛利；均无负商品差额，属于此前认可的花资源省人取舍。
- 综合出版社“综合出版／专业期刊／大众杂志”为横向业务，不要求科技时代递进。
- 游戏运营人数4000→3000→2000及咖啡厅设备用工下降是省工组的职责，不是主产人数不恒定。
- 畜牧场“露天牲畜栏／屠宰工具”无额外科技以及两档冷藏同为IV来自原版，保持谨慎，不套用模组新PM规则改原版。

## 单组升档检查

固定其他组为新档所属时代可用的最高营业档，逐组比较相邻生产档；不是全部混搭升级路径的穷举。毛利下降超过10个百分点的代表项仅有原版畜牧基础升级、私家庭园两次升级、乐器工坊一次升级；这些项目的人均年产值均上升。

私家庭园庭园苗圃→精细花圃毛利81.82%→68.75%，年产值11.70→14.30；精细花圃→玻璃花房毛利72.22%→57.58%，年产值16.90→24.70。乐器工坊金属加工→机械加工毛利51.85%→41.03%，年产值20.80→23.77。符合已认可的提高供给、允许较低毛利的原则。上述比例取整栋建筑同一上下文，不是PM单独毛利。

## 科技和商品连接

模组真正的升级线未发现重复或倒退时代，未发现多科技门槛；允许无继承关系的跨分支升级。启用建筑涉及的新商品均找到模组texticon声明。本轮未发现需要新增科技才能解决的缺口。

动物园高级表演额外投入观赏动物，水族馆仅在展览投入；两者定义不同，动物园表演动物与展览动物可解释为不同需求，不视为代码重复扣料错误。居民消费总量及商品需求配置仍按用户决定延期统一审查，不用理论组合推算市场供需平衡。

## 计算口径与限制

每级满员、商品基础价；合并投入产出修正，计入PM直接吞吐量。例如酒馆全高档计入15%吞吐量，投入4968、产出9660；咖啡厅全高档计入10%，投入13420、产出21780。直接商品差额年化后除员工，不扣工资。工资另以劳工年工资1及原版职业倍率估算。

理论组合未按国家科技、法律与市场筛选。时代表仅按era列可用最高营业档，不表示任何国家已拥有整个时代全部科技。没有模拟工资竞价、人口资格、就业不足、规模经济、州修正或游戏内GUI；静态纹理检查也不证明DDS渲染正常。本轮不重新逐项考据所有PM历史日期，延续先前已接受的日漫／魔法提前原则。
