# 动物培育园：当前实装

建筑由药学（II）解锁，每级主线固定 5,000 人。普通商业建筑，不占用原版畜牧场或耕地名额，采用轻工业建筑组。MUS在中央匈牙利、AQO在达尔马提亚各开局配置1级规范繁育、人工饲养，每座产观赏动物25，分别供应当地2级动物园需求10、5级水族馆需求25。

观赏动物基础价 60，是可交易的全局工业商品，表示标准化动物供应而非实际只数。合成食品基础价 30，统一代表配制饲料。主线不消耗工具或服务，设备组不增加产出。

## 科技及后续接入

- 科学饲养（III）：前置药学（II）、现代下水道（II）。
- 动物行为研究（IV）：前置科学饲养（III）。
- 两项科技已接入动物培育园和宠物店；动物园、水族馆的具体 PM 等对应建筑审核后接入。
- 宠物店已实装，观赏动物拥有建筑消费端；动物园、水族馆尚未接入。上表仍是基准价理论值，实际收益由市场价格和就业等条件决定。
- 居民消费需求、原版畜牧场和其他建筑的配方未修改。
- 临时复用既有动物图标，后续可以单独制作建筑、商品及科技图标。
