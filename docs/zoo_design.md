# 动物园：两条主线，当前实装

建筑解锁科技改为原版“药物”（pharmaceuticals，时代II），与动物培育园一致，避免先开放消费观赏动物的建筑而没有生产端。主PM原有科技保留；因此猛兽档在建筑解锁时也已可用。开局历史中预置的建筑是独立配置，不会因修改建造解锁科技而自动删除。

删除场地组和科普教育组，改为动物展览3000人、动物互动2000人，另加饲养设备组减劳工。导览、图文说明和基础自然教育并入展览内容及人员职责，不保留单独刊物配方。主组各档固定总人数，仅改变职业结构。展览基础价40，动物表演60；以下PM配方、人员、科技已实装，居民需求未改。

动物类型全档投入观赏动物，表演后两档另购演出动物。前两档喂食节目利用展区动物，不另购一批动物，额外投入代表活动饲料、讲解和接待。动物表演包含公开喂食、游客参与、驯兽节目及马戏演出。升级代表经营规模和专业化提高，不表示早期没有动物表演；演出动物采购抽象专业供应和节目规模扩大。

## 科技及开局衔接

建筑保持浪漫主义I解锁，动物培育园药学II解锁。MUS开局补药学，并在中央匈牙利配置1级规范繁育、人工饲养的动物培育园，产观赏动物25，供应当地2级动物园需求10。配置来自CSV。其他国家可在II时代自建培育园或通过贸易供应观赏动物；培育园配方与居民需求未改。

主线各档职业构成（劳工／店主／技工／职员）：展览为2500／300／0／200、2400／300／200／100、2200／200／400／200、2000／200／500／300；互动为1700／200／0／100、1600／200／0／200、1400／100／300／200、1200／100／400／300。所有组合均有足够劳工扣减2000。

旧场地、科普PM定义保留供旧引用使用，但建筑不再启用这些组。开局指定小型动物、饲养员投喂和人工饲养。尚未启动游戏验证。
